# Nokia Snake

A small Snake game made with plain HTML, CSS, and JavaScript. No installs or build tools are needed.

## Run the game

1. In VS Code, open the `Nokia Snake` folder with **File > Open Folder**.
2. In the Explorer panel, right-click `index.html` and choose **Reveal in File Explorer**.
3. Double-click `index.html` to open the game in your web browser.

You can also open the `Nokia Snake` folder in File Explorer and double-click `index.html` directly.

## Controls

- Arrow keys or WASD: steer
- Space: pause or resume
- Start game: begin or resume
- Restart: start over
- On touch screens, use the on-screen direction buttons
